\begin{frame}{What is going on?}
\vfill
\begin{itemize}
\item \LARGE The cthulu node first resolves the host.
\item  \LARGE Then connects to EPMD (Erlang Port Mapper Daemon) of the remote machine.
\item \LARGE This then allows it to connect to the port where Elixir node is running.
\end{itemize}
\vfill
\end{frame}
